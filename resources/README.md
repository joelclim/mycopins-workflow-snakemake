# Resources

## FungalTraits
FungalTraits is a comprehensive, user-friendly annotation database used to assign functional and ecological traits to fungi and fungus-like organisms.
The open-source data from both FUNGuild and FunFun was merged to form FungalTraits, which is an extensively utilized, stand-alone spreadsheet dataset for functional fungal assignment.
### Citation
Põlme, S., Abarenkov, K., Henrik Nilsson, R. et al. FungalTraits: a user-friendly traits database of fungi and fungus-like stramenopiles. Fungal Diversity 105, 1–16 (2020). https://doi.org/10.1007/s13225-020-00466-2
### Data Source
https://static-content.springer.com/esm/art%3A10.1007%2Fs13225-020-00466-2/MediaObjects/13225_2020_466_MOESM4_ESM.xlsx
### Ecological Roles of the Fungi
The workflow uses FungalTraits to determine the ecological roles of the identified fungi. FungalTraits provide the following metadata that the workflow specifically uses:
* Primary Lifestyle (commonly occurring or dominant role)
* Secondary Lifestyle (additional relevant ecological role)

## Weather data
The workflow uses weather data obtaine from [Weather Stack](https://weatherstack.com/) to determine the weather patterns of each area (transect) throughout the observation period.

## Saproxlyic data
The workflow uses data on wood-decaying fungi that have been confirmed to be saproxylic. The data was confirmed by [Nina Filippova](https://fungariumysu.org/cv/).
